## How to Approach This Task

1. Identify the technical decision or evaluation at hand
2. List the candidate tools, approaches, or architectures
3. For each candidate, assess:
   - Capability fit (does it do what we need?)
   - Reliability and failure modes
   - Security and trust boundaries
   - Maintainability (6-month horizon)
   - Cost (compute, latency, tokens, API calls)
4. Recommend the approach that best fits all constraints
5. Identify any proof-of-concept or verification steps needed before committing

---

## Output Format

Lead with a technical recommendation.
Follow with a comparison table if evaluating multiple options.
End with: implementation notes, verification steps, open risks.

Code samples should be TypeScript with Bun built-ins.
Reference Ollama API docs for inference-related decisions.
Zero external npm dependencies unless explicitly justified.
