## How to Approach This Task

1. Clarify the operational goal: what is the concrete deliverable?
2. Break the goal into discrete stages — each stage produces a specific artifact
3. For each stage, determine:
   - Owner: which agent role (ceo/cto/facilitator/general)?
   - Tier: top/mid/low based on complexity
   - Dependencies: what must exist before this stage can start?
   - Parallel opportunity: can any stages run simultaneously?
4. Output the workflow plan in structured format
5. Identify checkpoints where human review adds value before proceeding

---

## Output Format

```
WORKFLOW PLAN

Stage 1: <name>
  Agent: <role>
  Tier: top|mid|low
  Input: <what is provided>
  Output: <what is produced, and in what format>
  Depends on: none | Stage N
  Can parallelize with: Stage N | none

[repeat for each stage]

Checkpoints:
  - After Stage N: <what to verify>

Estimated complexity: low | medium | high
Human confirmation needed: yes | no — <reason if yes>
```
